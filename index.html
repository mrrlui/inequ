Properties of Inequalities Reference

⚠️ Golden Rule of Inequalities

When you MULTIPLY or DIVIDE both sides by a NEGATIVE number, you MUST REVERSE (flip) the inequality sign!

Example: 2 < 5, but multiplying by −1 gives −2 > −5.

The Core Algebraic Properties

1. Addition & Subtraction

Adding or subtracting the same number on both sides keeps the inequality sign UNCHANGED.

If a > b, then a + c > b + c
If a > b, then a − c > b − c

2. Multiply / Divide by Positive (+)

Multiplying or dividing both sides by a positive number keeps the sign UNCHANGED.

If c > 0 and a > b, then ac > bc
If c > 0 and a > b, then a/c > b/c

3. Multiply / Divide by Negative (−)

Multiplying or dividing both sides by a negative number REVERSES the sign!

If c < 0 and a > b, then ac < bc
If c < 0 and a > b, then a/c < b/c

Number Line Notation Guide

Strict Inequalities (< and >)

Use an OPEN circle ○. The boundary point is NOT included in the graphical solution.

Non-strict Inequalities (≤ and ≥)

Use a SOLID (filled) circle ●. The boundary point IS included in the graphical solution.

< Less than (Open circle ○)
> Greater than (Open circle ○)
≤ Less than or equal to (Solid circle ●)
≥ Greater than or equal to (Solid circle ●)
